# 📚 LearnKeep

LearnKeep is a smart Android knowledge tracking app that allows users to:

- Add and manage topics
- Add attachments (Images, PDFs, Files)
- Add YouTube links
- Select confidence level (1–10)
- Add one tag per topic
- Auto topic icon based on tag
- Search topics
- Store data locally using Room Database

---

## 🚀 Features

- 📷 Camera & Gallery Attachments
- 📄 PDF File Support
- 🔎 Search Functionality
- 🎯 Confidence Level Selector (1–10 colored circles)
- 🏷 Smart Tag-based Topic Icons
- 📺 Multiple YouTube Links
- 🌞 Always Light Mode
- 💾 Offline Local Storage (Room DB)
